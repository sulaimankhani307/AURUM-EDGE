 AURUM EDGE 

  A Multi-Confirmation  Trading Indicator for MetaTrader 5

AURUM EDGE  is a technical-analysis indicator for MetaTrader 5 (MT5), designed to identify potential BUY and SELL setups using trend alignment, momentum confirmation, and ATR-based reference levels.

Built for traders who value structured analysis, configurable signals, and clear chart-based information.

    Key Features

- EMA Trend Analysis: 9, 21, and 50 EMA alignment.
- RSI Confirmation: Momentum-based directional filtering.
- MACD Confirmation: Main-line and signal-line analysis.
- Multi-Factor Scoring: Configurable confirmation threshold from 1 to 5.
- BUY / SELL Signals: Chart arrows on qualifying closed candles.
- ATR Reference Levels: Indicative Stop Loss and Take Profit calculations.
- Signal Dashboard: On-chart information display.
- Alerts: Optional popup, sound, and push notifications.
- Customizable Settings:Adjust indicator parameters according to your analysis preferences.

    Installation Guide

1. Download `AURUM_EDGE_SK_SCALPER.mq5`.
2. Open MetaTrader 5.
3. Press `F4` to launch MetaEditor.
4. Open the MT5 Data Folder.
5. Navigate to `MQL5 → Indicators`.
6. Copy the downloaded `.mq5` file into that folder.
7. Open the file in MetaEditor.
8. Press `F7` to compile.
9. Return to MetaTrader 5 and refresh Navigator.
10. Drag the indicator onto your preferred chart.
